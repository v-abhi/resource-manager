Resource Manager

A simple, offline-first application to track and manage personal resources.

Features

- Track money, mobile data, time, and other resources.
- Configure daily, weekly, monthly, or yearly replenishment.
- Record consumption and additional resources.
- Choose between strict and flexible consumption limits.
- Carry forward unused balances or debt.
- View resource usage and expiry analytics.
- Sort and filter resources.
- Schedule morning and evening reminders on Android.
- Export and restore data using JSON backups.
- Light and dark themes.

Platforms

- Progressive Web App (PWA)
- Android APK (built using Capacitor)

Technology

JavaScript, CSS, Vite, Dexie.js, IndexedDB, and Capacitor.

Privacy

Resource data is stored locally on the user's device. No account is required.
